# Gaming Wiki

A private gaming wiki, starting with Darkest Dungeon 1 hero guides, positions,
team compositions, and illustrated trinket recommendations.

The first prototype will use plain HTML, CSS, and JavaScript, with game content
kept separate. Gameplay facts and item effects must be verified or clearly
flagged as unverified; DLC and mod requirements will be documented separately.

Current milestone: project preparation only. No website has been built yet.
Keep the project local; publishing, deployment, and pushing require explicit
instruction. See AGENTS.md for the project rules.
